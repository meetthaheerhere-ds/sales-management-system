🧾 Sales Management System

📌 Project Overview

This project is a Sales Management System developed using Python and MySQL. It helps manage sales data, customer records, and transactions efficiently.


🚀 Features

* Customer Management
* Sales Tracking
* Payment Handling
* Database Integration (MySQL)
* CSV Data Processing

---

🛠 Tech Stack

* Python
* MySQL
* Pandas

---

📁 Project Structure

* app.py → Main application
* db.py → Database connection
* mini_project.sql → Database schema
* data/ → CSV datasets

---

 ▶️ How to Run

1. Install dependencies

```bash
pip install pandas mysql-connector-python
```

2. Run project

```bash
python app.py
```
